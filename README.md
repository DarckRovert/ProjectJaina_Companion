# WoWPeru_Companion

**Hub social ligero del ecosistema WoW Perú.**

Addon de ~5 KB que conecta los addons del Reino Andino visualmente dentro del grupo.

## Funcionalidades

| Feature | Descripción |
|---|---|
| **Detección de addons** | Muestra qué addons WoW Perú tiene cada miembro del grupo |
| **Badge de modo** | Indica si un jugador está en modo Hardcore o Ironman |
| **Anuncio de BattlePass** | Anuncia en GROUP cuando alguien sube de nivel en el Pase |

## Comandos

```
/companion          → Muestra estado del ecosistema en el grupo
/companion scan     → Hace broadcast de tus addons activos al grupo
/companion debug    → Toggle de mensajes de debug
```

## Compatibilidad

- **WoW:** 3.3.5a (Build 12340)
- **Lua:** 5.1 puro
- **Requiere (opcional):** WoWPeru_BattlePass, WoWPeru_GameModes, WoWPeru_RaidSuite
